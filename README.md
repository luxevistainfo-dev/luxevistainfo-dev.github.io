# Pawlight

**One dollar. One meal. One more night safe.**

Live site: **https://luxevistainfo-dev.github.io/**

Pawlight is a public community fund for stray and surrendered dogs and cats. A $1 crypto gift is enough to put food in a bowl. Same wallet on Ethereum, Polygon, Base, Arbitrum, Optimism, BNB Smart Chain, Avalanche, and Bitcoin.
